☁️ Connect Google Drive
One-time setup (5 min). Your data will auto-save to a file called insurance_training_data.json in your Google Drive.
1
Go to Google Cloud Console
Visit console.cloud.google.com → Create a new project (name it anything, e.g. "Training System").
2
Enable Google Drive API
In your project → APIs & Services → Library → search "Google Drive API" → Enable it.
3
Create OAuth credentials
Go to APIs & Services → Credentials → Create Credentials → OAuth client ID.
Application type: Web application
Authorised JavaScript origins: add null (for local file) and your file's URL if hosted.
Copy the Client ID.
4
Configure OAuth consent screen
Go to OAuth consent screen → External → add your Gmail as a test user → Save.
5
Paste your Client ID below
